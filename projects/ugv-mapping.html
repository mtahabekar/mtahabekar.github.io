Project

Autonomous Unmanned Ground Vehicle

ROS, RViz, 2D LiDAR, 3D Mapping, ICP, AMCL, Motion Planning, Wireless Control, UGV

Overview

Autonomous UGV, designed and manufactured by Kolaydı, is an indoor mobile robot that produces a 3D map of an indoor environment using 2D LiDAR scans. It localizes itself on the generated map and can autonomously navigate to user-selected target locations, including targets that are not restricted to line-of-sight.

System Design

The system is organized around three main parts: perception, action, and user interface.

  • Perception includes LiDAR hardware, the mapping algorithm, and the localization algorithm.
  • Action includes motion planning, motion control, communication between the robot and user computer, the microcontroller, chassis, motors and drivers, and battery.
  • The user interface provides map visualization, robot state visualization, and a command interface through RViz.

Perception, Mapping, and Localization

The robot uses 2D LiDAR scans as the primary sensing input for indoor mapping. The project converts these scans into a 3D map, uses ICP registration in the mapping workflow, and uses AMCL localization so the robot can estimate its pose on the generated map.

Motion Planning and Control

The UGV plans paths to user-selected targets and can navigate to targets beyond line of sight. The system includes autonomous path planning and motion control, accounts for stationary obstacles, and updates the path when a dynamic or previously unmapped obstacle is detected.

User Interface

The project provides a wireless RViz-based interface between the robot and the user computer. The interface displays the generated map, planned path, robot location, and robot state, and it gives the user a command interface for selecting target locations.

Technical Specifications

Robot dimensions 20 cm diameter, 18 cm height
Weight 1 kg
Robot height requirement ≤ 30 cm
Communication Wireless communication between robot and user computer
User interface Interface for controlling the robot and visualizing map, path, and robot state
LiDAR rotation precision Under 2 degrees
Mapping Ability to merge map pieces from different grids; mapping error requirement ≤ 10%
Localization Localization error requirement ≤ 5 cm
Navigation Autonomous path planning and navigation; target-reaching error requirement ≤ 20 cm
Obstacle handling Stationary obstacles included in path planning; path updated when a dynamic obstacle is detected
Operating environment Indoor environment up to 8 m² with moderate obstacles

Results

  • The robot can generate a 3D map from 2D LiDAR scans.
  • The robot can localize itself on the generated map.
  • The robot can navigate autonomously to target points in the room.
  • The robot can adjust its path when a dynamic or previously unmapped obstacle is detected.
  • The robot communicates wirelessly with a computer.
  • The map, planned path, and robot location can be observed from the computer interface.
  • The poster includes localization, mapping, and motion-planning test result plots.
