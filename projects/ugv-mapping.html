Project

Autonomous UGV Mapping System

ROS, OctoMap, ICP, AMCL, 2D LiDAR, 3D Mapping

Overview

This project converted a 2D LiDAR into a 3D scanning system and used ROS-based mapping and localization methods for an autonomous UGV workflow.

Technical Approach

  • Converted a 2D LiDAR into a 3D scanning system using servo rotation.
  • Implemented OctoMap mapping for 3D occupancy mapping.
  • Used ICP registration and AMCL localization in ROS.

Tools and Technologies

ROS, OctoMap, ICP, AMCL, 2D LiDAR, servo-based scanning, 3D mapping.

Results or Impact

The system combined low-cost 2D LiDAR scanning with ROS mapping and localization components to support autonomous UGV mapping.

My Contribution

I worked on the LiDAR scanning conversion, ROS mapping stack, ICP registration, and AMCL-based localization components.
