Master’s Project

Real-Time Cloth Simulation and Obstacle-Aware Control for Deformable Object Manipulation

ROS2, Isaac Sim, NVIDIA Newton, Style3D, Cloth Simulation, Control Barrier Functions, Python

Overview

This project developed a simulation-stage framework for obstacle-aware cloth manipulation. The work replaced a simplified ROS1/PBD-style cloth model with a ROS2-compatible Isaac Sim and NVIDIA Newton Style3D pipeline. The system simulates sheet-like deformable objects, exposes anisotropic fabric parameters, publishes cloth state and corner poses through ROS2, and integrates an external Control Barrier Function controller for follower-corner obstacle avoidance.

Motivation

Deformable-object manipulation is harder than rigid-object manipulation because cloth shape changes continuously under gravity, contact, friction, bending, sagging, wrinkles, folds, and external forces. A useful simulator must be fast enough for closed-loop use while remaining realistic enough that controller decisions are meaningful.

System Architecture

  • The upper cloth corners act as leader-side inputs, corresponding to a human-held or teleoperated side.
  • The lower cloth corners act as follower-side control points.
  • Keyboard or scripted teleoperation publishes leader velocity commands.
  • Isaac Sim applies the commands, advances the Newton/Style3D cloth simulation, and publishes deformable-object state.
  • An obstacle-distance node computes the closest cloth-obstacle distance.
  • A CBF controller receives leader commands, corner poses, and obstacle distance, then publishes safe follower-corner velocity commands.

Simulation Framework

Isaac Sim provides the robotics-oriented scene, visualization, USD stage, rendering, and ROS2 integration. NVIDIA Newton provides the GPU-oriented physics backend, while Style3D provides the cloth solver and anisotropic fabric parameters.

  • The cloth uses a default 56 × 56 cell grid, giving 57 × 57 = 3249 particles.
  • The cell size is 0.015 m, producing an approximately 0.84 m × 0.84 m sheet.
  • Patch-based corner pinning controls a 3 × 3 particle patch at each corner, avoiding unrealistic single-particle constraints.
  • The simulation publishes cloth point cloud state and corner poses, and subscribes to leader and follower velocity commands.

Obstacle-Aware CBF Controller

The controller modifies follower-corner velocity commands when the simulated cloth approaches the table obstacle or violates stretch limits. A nominal follower command tracks the corresponding leader motion and includes a formation-recovery term. The obstacle-distance node reports the minimum signed distance between the cloth and table obstacle, and the CBF safety layer modifies commands only when safety constraints become active.

The implementation uses a geometric obstacle Jacobian approximation as an interim fast method. The controller is structured so future finite-difference Newton rollouts can replace the geometric Jacobian with a simulation-derived sensitivity estimate.

Experiments and Results

  • CBF on/off comparison: with CBF disabled, the cloth hits or penetrates the table; with CBF enabled, the controller prevents penetration in the main experiment.
  • The result is best described as collision avoidance, not perfect enforcement of the 0.05 m safety margin.
  • Resolution sweep: increasing cloth resolution improves visual smoothness but reduces simulation rate. The 56 × 56 setting is a practical compromise near 30 Hz on the tested laptop.
  • Leader-speed sweep: high leader speed can cause near-contact or failure because follower velocity limits, the geometric Jacobian approximation, and delayed cloth motion limit the controller response.
  • Friction and stiffness sweeps: Style3D parameters visibly affect sliding, wrinkling, sagging, and rigidity.
  • External CBF computation remains lightweight, around sub-millisecond scale, while cloth simulation dominates runtime at high resolution.

Limitations and Future Work

  • This is a simulation-stage framework, not yet a physical real-fabric manipulation system.
  • Parameters are not calibrated against physical cloth measurements.
  • The geometric Jacobian is an interim approximation.
  • The controller commands idealized cloth corner targets, not full robot arms with gripper compliance and robot-body collision constraints.
  • Future work includes perception-to-simulation calibration with RGB-D and ArUco markers, rollout-based Jacobian estimation, and real-robot deployment.
