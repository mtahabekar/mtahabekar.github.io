Project

Deformable Object Manipulation

ROS, RGB-D, ArUco, Kalman Filtering, NVIDIA Isaac Sim, Kinova Gen2

Overview

This research focuses on real-time perception and state estimation for planar deformable objects, with simulation in NVIDIA Isaac Sim and coordinated manipulation using Kinova Gen2 dual-arm robots.

Technical Approach

  • Built a perception and state-estimation pipeline using an RGB-D camera, ArUco marker tracking, Kalman filtering, and ROS.
  • Simulated deformable 2D linear objects with the Newton 1.0 Physics engine in NVIDIA Isaac Sim.
  • Extended a ROS-based dual-arm manipulation framework for coordinated manipulation of flexible 2D materials.

Tools and Technologies

ROS, RGB-D sensing, ArUco markers, Kalman filtering, NVIDIA Isaac Sim, Newton 1.0 Physics engine, Kinova Gen2 manipulators.

Results or Impact

The work produced a real-time perception and state-estimation pipeline and improved simulation support for sim-to-real consistency in deformable object manipulation experiments.

My Contribution

I developed the perception and state-estimation pipeline, worked on Isaac Sim deformable-object simulation, and extended the ROS dual-arm manipulation framework.
